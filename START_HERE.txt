START HERE
==========
1. Download train.csv from:
   https://www.kaggle.com/c/house-prices-advanced-regression-techniques/data
2. Place it in this folder at data/train.csv.
3. Open this folder in VS Code and follow README.md.
4. Install packages: pip install -r requirements.txt
5. Train: python train_model.py
6. Try a command-line prediction: python predict.py --area 1500 --bedrooms 3 --bathrooms 2
7. Optional web app: streamlit run app.py
8. Fill PROJECT_REPORT_TEMPLATE.md with metrics generated by your run.
